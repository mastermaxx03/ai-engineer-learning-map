# AI Engineer Learning Map

An interactive, hand-drawn map of everything needed to prepare for AI engineer and forward deployed engineer roles.

Every topic is drawn as one part of a single agent you build. Click a part to see what it needs first, what it unlocks next, and the four moves that prove you have learned it: explain, build, break, and retest after 14 days. The stage buttons show the agent growing from "talk to a model" to "get hired".

Open `index.html` in a browser, or view it on GitHub Pages.
